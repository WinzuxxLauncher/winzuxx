Winzuxx Launcher — сайт на Flask (Minecraft-лаунчер)
======================================================

Запуск:
  1) pip install -r requirements.txt
  2) python app.py
  3) Открой http://localhost:5000

Регистрация / вход:
  - Страницы /register и /login.
  - Пароли хранятся в базе не в открытом виде (хэшируются).
  - После входа сессия сохраняется в подписанной куке — пользователь
    остаётся залогинен, пока не нажмёт "Выйти" или не очистит куки.
  - Пользователи хранятся в файле users.db (SQLite), он создаётся
    автоматически при первом запуске.

Секретный ключ:
  В app.py есть строка:
      app.secret_key = "change-this-to-a-random-secret-key"
  Перед выкладкой на реальный сервер замени её на длинную случайную строку —
  от неё зависит защита кук сессии.

Куда вставить ссылку на скачивание лаунчера:
  В app.py найди строку:
      DOWNLOAD_URL = "https://example.com/winzuxx-launcher-setup.exe"
  и замени на свою прямую ссылку.
  Если хочешь раздавать файл со своего сервера — положи его в static/
  и укажи DOWNLOAD_URL = "/static/имя_файла.exe"
